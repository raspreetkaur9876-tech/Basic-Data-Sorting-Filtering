# Basic Data Sorting & Filtering Project

## Project Overview
This project demonstrates basic data sorting and filtering using Microsoft Excel. A sales dataset is used to organize records, find specific information, and answer simple business questions.

## Objectives
- Sort sales totals from highest to lowest.
- Filter sales by region.
- Filter orders based on quantity.
- Filter records by salesperson.
- Answer business questions using the filtered data.

## Tools Used
- Microsoft Excel
- Sales dataset in CSV format

## Dataset Columns
- Order ID
- Date
- Product
- Quantity
- Unit Price
- Total
- Region
- Salesperson

## Tasks Performed
1. Imported the sales dataset into Excel.
2. Converted the data into an Excel table.
3. Sorted the Total column from largest to smallest.
4. Filtered records for the West region.
5. Applied a quantity filter greater than 5.
6. Filtered records by salesperson.
7. Prepared a separate sheet containing business questions and answers.

## Key Learning
This project helped me practice sorting, filtering, organizing sales records, and finding useful information from a dataset using Excel.

## Conclusion
Sorting and filtering make sales data easier to understand and help users find relevant records quickly. This project provided practical experience with basic Excel data analysis.
